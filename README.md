# LLM From Scratch

This repository contains my exercises and code implementations while studying Sebastian Raschka's book, *Build a Large Language Model (From Scratch)*.

The goal is to gain a deeper understanding of how Large Language Models work by implementing their core components in Python and PyTorch.

## Topics Covered

- Text tokenization
- Token embeddings
- Positional embeddings
- Self-attention mechanisms
- Transformer architecture
- GPT model implementation
- Model training and fine-tuning

## Technologies

- Python
- PyTorch
